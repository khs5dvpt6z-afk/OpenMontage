# Old West "Stranger" — 16 s cinematic test

Fully coded 3D animation (Blender 5.2 `bpy` + Cycles CPU) synced to the supplied ElevenLabs narration.
All geometry, materials, animation, music and sound effects are generated by the scripts in `src/`.
No third-party models, textures, samples or music are used.

## Layout
| path | content |
|---|---|
| `audio/narration.mp3` | supplied narration (used unchanged) |
| `src/timeline.py` | measured phrase timings, shot list, piano-stop time |
| `src/music.py` | original score + diegetic saloon-piano note lists |
| `src/bl_util.py`, `bl_env.py`, `bl_chars.py` | geometry / material helpers, town + saloon, people + horse rigs (analytic IK) |
| `src/build_scene.py` | builds and animates everything → `build/oldwest.blend`, `build/events.json` |
| `src/render.py` | renders frames with Cycles (per-shot samples / exposure) |
| `src/export_cams.py` | dumps camera path → `build/cams.json` (audio panning) |
| `src/audio_mix.py` | synthesizes score, piano, chatter, wind, room tone, foley; mixes → `audio/final_mix.wav` + `audio/stems/` |
| `src/assemble.sh` | grade + encode → `final/oldwest_stranger_test.mp4` |

## Reproduce
```bash
uv venv -p python3.13 wwenv && VIRTUAL_ENV=wwenv uv pip install bpy==5.2.3 numpy scipy soundfile faster-whisper
ffmpeg -i audio/narration.mp3 -ar 48000 -ac 1 audio/narration_48k.wav
cd src
../wwenv/bin/python build_scene.py          # ~15 s
../wwenv/bin/python export_cams.py
../wwenv/bin/python render.py --frames 0-479 --out ../renders/frames   # ~3-4 h on 4 CPU cores
../wwenv/bin/python audio_mix.py
./assemble.sh
```

## Audio sources / licensing
Everything except the narration is **original and synthesized in `src/audio_mix.py`** (numpy/scipy):
Karplus-Strong acoustic guitar, additive low strings, additive honky-tonk upright piano (original
G-major melody), formant-babble chatter (no words), filtered-noise wind/room tone, modal/stick-slip foley
(hooves, saddle creaks, reins, cloth, boots + spurs, door hinges, chair, glass, floorboard).
No external recordings or copyrighted themes → no third-party licence restrictions; safe for monetized use
(narration rights follow your ElevenLabs plan).
